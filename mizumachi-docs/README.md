# Mizumachi 申請書類自動生成フォーム（東京都水道局様式）

`index.html` をブラウザで開くだけで動きます（インストール・通信不要）。

## できること

1セットの入力データ（申込者・工事場所・指定事業者・主任技術者・工事内容など）から、
東京都水道局の給水装置工事関係書類 6 種類を自動生成し、A4 プレビュー表示と
印刷（PDF保存）ができます。

| 様式番号 | 書類名 |
|---|---|
| 様式1-3 | 給水装置工事申請申込書 |
| 様式2-1 | 指定給水装置工事事業者工事調書 |
| 様式37-2 | 指定給水装置工事事業者工事検査申込書 |
| 様式3-1 | 給水装置工事取消・設計変更・施行延期届 |
| 様式277 | 給水装置関係各種届出書 |
| 参考様式 | 委任状 |

様式の構成・記載項目は「指定給水装置工事事業者工事施行要領（令和8年4月・東京都水道局）」
（このリポジトリの `src/data/specifications.json` に収録）を基に再現しています。

## 使い方

1. `index.html` をダブルクリックしてブラウザで開く
2. 左のフォームに入力する（「サンプル入力」ボタンでお試しデータが入ります）
3. 右の書類リストから「プレビュー」→ A4 画面で確認
4. 「印刷 / PDF保存」→ ブラウザの印刷ダイアログで「PDFとして保存」を選ぶ

入力内容はブラウザ内（localStorage）に自動保存され、次回開いたときも残っています。

## 注意

- 本フォームは**再現様式**です。実際の提出には[東京都水道局の公式様式一覧](https://www.waterworks.metro.tokyo.lg.jp/jigyosha/koji/yoshiki/koji)の最新様式をご利用ください。
- mizumachi-prototype（事業者側UI）の「申請書類」タブへ移植できるよう、
  `S.docData` / `renderDoc_*` 関数 / `[data-doc-*]` イベント委譲という
  プロトタイプと同じ構成で実装しています。`<style>` の書類部分と
  `<script>` 内の各関数をコピーすれば組み込めます。
