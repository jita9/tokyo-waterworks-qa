# Mizumachi プロトタイプ（クラウド版・新規立ち上げ）

`index.html` をブラウザで開くだけで動きます（インストール・通信不要、1ファイル完結）。

旧 Cowork artifact 版 `mizumachi-prototype` の後継として、この GitHub リポジトリ上で
新規に立ち上げたバージョンです。

## 画面構成

### 事業者モード
| タブ | 内容 |
|---|---|
| 🏠 ダッシュボード | 案件一覧・KPI（AI審査中／申請中／承認済み） |
| 📝 新規申請 | 5ステップのウィザード。完了すると案件が作られ、AI審査・書類生成へデータが流れる |
| 🤖 AI審査 | 申請前のAI事前チェック（記載漏れ・口径・共同住宅の事前調査要否など） |
| 📐 Web-CAD | 配水管・給水管・メータ・止水栓・給水栓を配置する平面図スケッチ |
| 📄 申請書類 | 東京都水道局の現行様式6種類（様式1-3／2-1／37-2／3-1／277／委任状）を自動生成。A4プレビュー＋印刷/PDF |
| 💧 水理計算 | ウェストン公式による損失水頭計算と余裕水頭判定 |
| 🕘 履歴 | 案件ごとのタイムライン |
| 📚 ルール参照 | 工事施行要領（令和8年4月・東京都）からの要点集。キーワード検索付き |

### 自治体モード（Checker）
ヘッダーのボタンで切替。事業者が「東京都へ審査申請」した案件が審査キューに届き、
AI事前審査の結果つきで承認／差戻しができる。

## データの流れ（このプロトタイプの肝）

```
新規申請ウィザードで1回入力
   ├→ 案件（ダッシュボード・履歴）
   ├→ AI事前審査
   ├→ 申請書類6種に自動転記（様式1-3ほか）
   └→ 審査申請 → 自治体側Checkerの審査キューへ
```

入力・案件・図面はすべてブラウザ内（localStorage）に保存されます。

## 注意

書類様式は「指定給水装置工事事業者工事施行要領（令和8年4月・東京都水道局）」
（`../src/data/specifications.json` に全文収録）に基づく再現です。
実際の提出には[公式様式](https://www.waterworks.metro.tokyo.lg.jp/jigyosha/koji/yoshiki/koji)をご利用ください。
